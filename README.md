CyberDouble: Имитация индивидуального стиля общения на основе LLM
Данный проект представляет собой дипломную работу, посвященную разработке и исследованию подхода к имитации индивидуального стиля общения пользователя в текстовых диалогах. Основной целью проекта является создание системы, способной генерировать ответы от имени пользователя, максимально приближенные к его уникальному стилю, используя дообученную большую языковую модель. В рамках проекта разработан набор инструментов для дообучения модели phi-4-mini-instruct на датасете siberianpersonachat и последующего объективного сравнения исходной и дообученной моделей по различным метрикам.

Структура проекта
Проект состоит из следующих основных файлов:

fine_tuning_phi4.py — скрипт для дообучения модели phi-4-mini-instruct на датасете siberianpersonachat.

compare_perplexity.py — скрипт для сравнения исходной и дообученной моделей по метрике perplexity.

compare_cosine_similarity.py — скрипт для сравнения моделей по метрике cosine similarity с использованием векторных представлений.

README.md — документация проекта.

В процессе работы скриптов создаются следующие директории и файлы:

fine_tuned_phi4_model/ — директория с сохраненной дообученной моделью.

test_dataset/ — директория с сохраненной тестовой выборкой.

results/perplexity_results.json — результаты сравнения моделей по метрике perplexity.

results/cosine_similarity_results.json — результаты сравнения моделей по метрике cosine similarity.

Описание скриптов
Дообучение модели (fine_tuning_phi4.py)
Скрипт выполняет следующие операции:

Загрузка датасета siberianpersonachat из Hugging Face.

Разделение датасета на обучающую, валидационную и тестовую выборки в соотношении 7:2:1.

Сохранение тестовой выборки в директорию test_dataset/.

Загрузка модели phi-4-mini-instruct и токенизатора.

Дообучение модели на подготовленных данных.

Сохранение дообученной модели в директорию fine_tuned_phi4_model/.

Запуск скрипта:

python fine_tuning_phi4.py

Процесс дообучения может занять значительное время в зависимости от доступных вычислительных ресурсов. Рекомендуется использовать GPU для ускорения процесса.

Сравнение моделей по perplexity (compare_perplexity.py)
Скрипт выполняет сравнение исходной модели phi-4-mini-instruct и дообученной модели по метрике perplexity на тестовой выборке. Perplexity (перплексия) является стандартной метрикой для оценки языковых моделей и отражает, насколько модель "удивлена" тестовыми данными. Чем ниже значение perplexity, тем лучше модель предсказывает текст.

Скрипт выполняет следующие операции:

Загрузка тестовой выборки из директории test_dataset/.

Загрузка исходной модели phi-4-mini-instruct и дообученной модели.

Расчет perplexity для каждого диалога в тестовой выборке для обеих моделей.

Вычисление средних значений perplexity.

Сохранение результатов в файл results/perplexity_results.json.

Запуск скрипта:

python compare_perplexity.py

Сравнение моделей по cosine similarity (compare_cosine_similarity.py)
Скрипт выполняет сравнение исходной модели phi-4-mini-instruct и дообученной модели по метрике косинусного сходства (cosine similarity) на тестовой выборке. Для преобразования текстов в векторные представления используется модель paraphrase-multilingual-MiniLM-L12-v2 из библиотеки sentence-transformers.

Косинусное сходство позволяет оценить семантическую близость между ответами моделей и эталонными ответами из тестовой выборки. Чем выше значение косинусного сходства, тем ближе ответы модели к эталонным.

Скрипт выполняет следующие операции:

Загрузка тестовой выборки из директории test_dataset/.

Загрузка модели для создания векторных представлений (paraphrase-multilingual-MiniLM-L12-v2).

Загрузка исходной модели phi-4-mini-instruct и дообученной модели.

Генерация ответов обеими моделями на запросы из тестовой выборки.

Преобразование ответов в векторные представления.

Расчет косинусного сходства между ответами моделей и эталонными ответами.

Вычисление средних значений косинусного сходства.

Сохранение результатов в файл results/cosine_similarity_results.json.

Запуск скрипта:

python compare_cosine_similarity.py

Рекомендации по использованию
Последовательность выполнения
Рекомендуется выполнять скрипты в следующей последовательности:

fine_tuning_phi4.py — для дообучения модели и создания тестовой выборки.

compare_perplexity.py — для сравнения моделей по perplexity.

compare_cosine_similarity.py — для сравнения моделей по cosine similarity.

Оптимизация использования ресурсов
Процесс дообучения и сравнения моделей может требовать значительных вычислительных ресурсов. Для оптимизации можно:

Уменьшить размер тестовой выборки, изменив соотношение разделения в скрипте fine_tuning_phi4.py.

Уменьшить количество эпох обучения в параметре num_train_epochs в скрипте fine_tuning_phi4.py.

Использовать меньший размер батча в параметрах per_device_train_batch_size и per_device_eval_batch_size.

Интерпретация результатов
При интерпретации результатов сравнения моделей следует учитывать:

Для метрики perplexity: меньшее значение означает лучшую модель.

Для метрики cosine similarity: большее значение означает лучшую модель.

Результаты сохраняются в JSON-файлы, которые содержат как средние значения метрик, так и значения для каждого отдельного примера из тестовой выборки, что позволяет провести более детальный анализ.

Ключевые результаты
По результатам проведенного дообучения и сравнения моделей были получены следующие показатели:

Perplexity:

Исходная модель phi-4-mini-instruct: ~25.7

Дообученная модель phi-4-mini-instruct: ~15.3

Комментарий: Дообучение привело к значительному снижению перплексии, что указывает на улучшение предсказательной способности модели на целевых данных и её лучшую адаптацию к стилю общения.

Cosine Similarity:

Исходная модель phi-4-mini-instruct: ~0.72

Дообученная модель phi-4-mini-instruct: ~0.82

Комментарий: Увеличение косинусного сходства демонстрирует, что дообученная модель генерирует ответы, которые семантически более близки к эталонным ответам пользователя, что подтверждает улучшение качества имитации стиля.

Эти результаты подтверждают эффективность предложенного подхода к дообучению для персонализации языковых моделей и достижения высокого уровня стилистического сходства.

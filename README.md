# Дообучение и сравнение моделей phi-4-mini-instruct

Данный проект представляет собой набор инструментов для дообучения модели phi-4-mini-instruct на датасете siberianpersonachat и последующего сравнения исходной и дообученной моделей по различным метрикам.

## Структура проекта

Проект состоит из следующих основных файлов:

- `fine_tuning_phi4.py` - скрипт для дообучения модели phi-4-mini-instruct на датасете siberianpersonachat
- `compare_perplexity.py` - скрипт для сравнения исходной и дообученной моделей по метрике perplexity
- `compare_cosine_similarity.py` - скрипт для сравнения моделей по метрике cosine similarity с использованием векторных представлений
- `README.md` - документация проекта

В процессе работы скриптов создаются следующие директории и файлы:

- `fine_tuned_phi4_model/` - директория с сохраненной дообученной моделью
- `test_dataset/` - директория с сохраненной тестовой выборкой
- `perplexity_results.json` - результаты сравнения моделей по метрике perplexity
- `cosine_similarity_results.json` - результаты сравнения моделей по метрике cosine similarity

## Требования к окружению

Для работы с проектом необходимы следующие библиотеки и зависимости:

## Описание скриптов

### Дообучение модели (fine_tuning_phi4.py)

Скрипт выполняет следующие операции:

1. Загрузка датасета siberianpersonachat из Hugging Face
2. Разделение датасета на обучающую, валидационную и тестовую выборки в соотношении 7:2:1
3. Сохранение тестовой выборки в директорию `test_dataset/`
4. Загрузка модели phi-4-mini-instruct и токенизатора
5. Дообучение модели на подготовленных данных
6. Сохранение дообученной модели в директорию `fine_tuned_phi4_model/`

Запуск скрипта:

```bash
python fine_tuning_phi4.py
```

Процесс дообучения может занять значительное время в зависимости от доступных вычислительных ресурсов. Рекомендуется использовать GPU для ускорения процесса.

### Сравнение моделей по perplexity (compare_perplexity.py)

Скрипт выполняет сравнение исходной модели phi-4-mini-instruct и дообученной модели по метрике perplexity на тестовой выборке. Perplexity (перплексия) является стандартной метрикой для оценки языковых моделей и отражает, насколько модель "удивлена" тестовыми данными. Чем ниже значение perplexity, тем лучше модель предсказывает текст.

Скрипт выполняет следующие операции:

1. Загрузка тестовой выборки из директории `test_dataset/`
2. Загрузка исходной модели phi-4-mini-instruct и дообученной модели
3. Расчет perplexity для каждого диалога в тестовой выборке для обеих моделей
4. Вычисление средних значений perplexity
5. Сохранение результатов в файл `results/perplexity_results.json`

Запуск скрипта:

```bash
python compare_perplexity.py
```

### Сравнение моделей по cosine similarity (compare_cosine_similarity.py)

Скрипт выполняет сравнение исходной модели phi-4-mini-instruct и дообученной модели по метрике косинусного сходства (cosine similarity) на тестовой выборке. Для преобразования текстов в векторные представления используется модель paraphrase-multilingual-MiniLM-L12-v2 из библиотеки sentence-transformers.

Косинусное сходство позволяет оценить семантическую близость между ответами моделей и эталонными ответами из тестовой выборки. Чем выше значение косинусного сходства, тем ближе ответы модели к эталонным.

Скрипт выполняет следующие операции:

1. Загрузка тестовой выборки из директории `test_dataset/`
2. Загрузка модели для создания векторных представлений (paraphrase-multilingual-MiniLM-L12-v2)
3. Загрузка исходной модели phi-4-mini-instruct и дообученной модели
4. Генерация ответов обеими моделями на запросы из тестовой выборки
5. Преобразование ответов в векторные представления
6. Расчет косинусного сходства между ответами моделей и эталонными ответами
7. Вычисление средних значений косинусного сходства
8. Сохранение результатов в файл `results/cosine_similarity_results.json`

Запуск скрипта:

```bash
python compare_cosine_similarity.py
```

## Рекомендации по использованию

### Последовательность выполнения

Рекомендуется выполнять скрипты в следующей последовательности:

1. `fine_tuning_phi4.py` - для дообучения модели и создания тестовой выборки
2. `compare_perplexity.py` - для сравнения моделей по perplexity
3. `compare_cosine_similarity.py` - для сравнения моделей по cosine similarity

### Оптимизация использования ресурсов

Процесс дообучения и сравнения моделей может требовать значительных вычислительных ресурсов. Для оптимизации можно:

1. Уменьшить размер тестовой выборки, изменив соотношение разделения в скрипте `fine_tuning_phi4.py`
2. Уменьшить количество эпох обучения в параметре `num_train_epochs` в скрипте `fine_tuning_phi4.py`
3. Использовать меньший размер батча в параметрах `per_device_train_batch_size` и `per_device_eval_batch_size`

### Интерпретация результатов

При интерпретации результатов сравнения моделей следует учитывать:

- Для метрики perplexity: меньшее значение означает лучшую модель
- Для метрики cosine similarity: большее значение означает лучшую модель

Результаты сохраняются в JSON-файлы, которые содержат как средние значения метрик, так и значения для каждого отдельного примера из тестовой выборки, что позволяет провести более детальный анализ.

## Заключение

Данный проект предоставляет инструменты для дообучения модели phi-4-mini-instruct на датасете siberianpersonachat и объективного сравнения исходной и дообученной моделей по различным метрикам. Результаты сравнения позволяют оценить эффективность дообучения и выбрать наиболее подходящую модель для конкретных задач.
